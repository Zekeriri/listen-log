一篇简短的文章：蹩脚的孩子们涌向原版的北斗神拳

一口エッセイ:初代北斗の拳に群がるクソガキたち

スマスロ北斗の拳を打ちました。懐古目的です。もう上京したての頃のように、家賃をサンドに突っ込んで文字通り命を削ってドキドキする焦燥感は得られませんからね。余裕のあるギャンブルなんて楽しくないのさ。狂気の沙汰ほどおもしろい……！ 懐かしいですよね、初代北斗。構成が大胆。ただケンシロウが散歩しているだけで、時折バットがどっか行ったり戻ってきたりするだけ。演出過多の現代では考えきれないシンプルさだ。バトルボーナスはちょっとゲーム性が増していて驚きました。昔は本当にラオウに豪掌破撃たれないよう祈るだけしかできなかったのに、ストックまで搭載されて……（ ; ; ） プレミア引いたぜ。演出としてはいいけど、関係ないパチンコのボタンにまでなるなよエイリやん。 さてさて、懐かしさで打った感想としては大満足です。バトルボーナスをゲットした際の高揚感、オーラ判別から攻防の緊張、何もかも当時のままだ。 小学生の頃、アミューズメント機で打ちまくっていたんですよ。もう猿みたいに群がった。地元のジャスコに2台だけ置いてましてね。普通のメダルゲームならせいぜい50枚が大当たりなのに、北斗ならラオウ昇天されると2000枚以上手に入る。メダルゲームで2000枚ですから一生遊べます。一瞬でメダル界の王、メダルキングに昇格。当然メダルで永久の暇つぶしをしたいクソガキたちは、放課後になると即北斗へ座るのだ。 クソガキの青春だった。まだ珍しいAT方式。隣のハクション大魔王もそうだったけれど、あっちは魔王が空から釣りしているだけで迫力なかったからね。ケンシロウとラオウが対峙するたび、今回のバトルはどこまで伸びるんだとゲーセン中のクソガキや、朝からメダルゲームに没頭する終わった老人が見学するため背後に集合するんです。ただのパチスロに観客が湧く。 ラオウのパンチをケンシロウが避けるたび、ラウンドに入った瞬間にトキやレイなど強敵（とも）が映るたび、ゲーセンに入り浸るボンクラたちが大興奮。さながら、まだテレビが無かった昭和時代にみんなで力道山の試合を観戦するかのような熱狂。本物のパチ屋ではあり得ない光景。そして、ついに誰かがラオウを天に還したとき、ゲーセン中の人たちが拍手で迎える。そんな暖かい光景が小禄のジャスコにはあった。 現代ではボーナス当選しても黙々と打つだけだし、どこのゲーセンでもアミューズメント機のスロなんて注目されてないでしょう。あの一瞬だけの不思議な体験だ。吉宗とかも打ち続けたなぁ。「いつか本当のパチスロで大儲けしてやるんだい！」と思い込んでましたから、18になった瞬間には立派なスロカスでしたね。何もかもみな懐かしい。DJラオウ、お前は今どこで戦っている……。（調べたら最近スマスロ化記念で復活したらしい） 倒れるたびにリンちゃんが名前を呼んでくれたおかげで、＋7kでした。 パチンコの景品って、パチンコの景品すぎるよね。 毎日の日記をまとめた同人誌や商業エッセイ集をよろしくね♪ 新刊でたばかりだぜ！
