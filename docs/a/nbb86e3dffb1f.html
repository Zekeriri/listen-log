あの正しい部屋の夢を見て目が回る」というフレーズが、これまた良い……。「正しい部屋」、解釈次第ではありますが、この窮屈さはたしかにわかる。タイトルはもちろんWinkの名曲『淋しい熱帯魚』がモチーフでしょう。 ・アイデン貞貞メルトダウン/えなこ feat.P丸様。 『おにまい』という正しく王道な萌えアニメに対して、パーフェクトな回答としての直球電波曲。この作品に対して、この主題歌以外のベストマッチはありえないでしょう。そもそも電波曲自体が非常に調整が難しく正解がないジャンルに対し、ここまで万人が「萌えアニメらしい完璧な電波だ」と認めるようなリズムとフレーズを作れる時点で100点。 ・Brain Power Neuro-sama (Cover) AIキャラクターが配信するという近未来的な試みで話題のNeuro-samaの歌ってみた。原曲は音ゲーの曲らしく、人間が歌うことを想定していないのですが、どんな歌だろうと文字さえあれば読み上げることができるAIだからこそ再現できたサビが最高に気持ち良い。 Neuro-samaの歌ってみたは数あれども、「AIでしか歌うことができない奇跡」としては、この『Brain Power』が一番ではないでしょうか。サビが本当に爽快なんです。これが未来か。 ・Signal/浜崎あゆみ 浜崎あゆみのマイナー曲を掘っています。 これが、とても良い。そもそも浜崎あゆみの曲自体がエーベックス全体で懐かしさにあふれており、令和の現代に聴くと直球で90年代後半すぎて逆に良い。 この曲あたりのアルバム収録曲は、聴き馴染みが深い代表曲とちがって歌詞が特徴的で「わかりやすさ」を外しているのが、また良いんです。敢えて狙ってない曲を作っている感じが刺さる。このふわっとした比喩と綺麗事のバランスが90年代な空気感でクセになる。 ・仮面の忍者 赤影/秋保和也・秋保浩司（fromキャロットクラブ） カッコいい。 あまりにカッコよすぎて、それしか言うことがない。時代を先取りしたスタイリッシュなサビと、一昔前の野太い優しさを感じさせるボーカルのバランスが良い。やっぱりタイトルを叫んでくれるがいいよね。それも2回も言ってくれるから、盛り上がりどころがわかり易い。これこそアニソンらしいキャッチーさだなと感じる一曲。 ・集結の園へ(AYANAMI ver.) パチンコエヴァの有名曲『集結の園へ』の綾波が歌ったという体のバージョン。最近、ゴジラと戦っているパチンコエヴァで新バージョンも追加されたようで聴いてみましたが、やっぱり原曲がいいな～ってなったところで、こっちも久々に聴いてみた。 こちらは大胆なアレンジで、あれだけアニメチックに激しかった曲が、まるで穏やかな母性に包まれる子守唄と化している。このテンポだとサビの「おやすみなさい」のフレーズが、本当に聞き手を寝かしつけてくれているようで就寝前にオススメです。原曲は「おやすみなさい」と言いつつ寝かせる気ないからね。 アスカが歌っている『心よ原始に戻れ』も、あのミスマッチなギャップが独特の味があって好き。 ・早くしてよ/久宝留理子 久宝留理子いいよね……。勝ち気で男を振り回すような曲が多くて、森高千里が切り拓いた「女性優位」な曲の文化を感じます。そのうえで、この『早くしてよ』は、そんな自分が恋に堕ちてしまった弱さも表現されていて、まだツンデレなる概念が人口に膾炙していない時代の「勝ち気な女性の弱さ」が垣間見えて素敵です。 ・Everything Counts/Depeche Mode AIに僕が好きなアーティストを入力しまくったら、「アナタはデペッシュ・モードを聴きなさい！」と言われたので、代表曲を聴いてみた。 ……いい！ ニュー・オーダーのような優しいテクノで心が落ち着く。これはたしかに僕が好きなタイプだ。まだまだ人工知能には粗も多いですが、こうして好きなアーティストや作家を入力し、オススメを聴きだして掘ってみるという使い道はすごく便利ですね。次にどこへ行けばいいのか示してくれる道標。先述したNeuro-Samaと合わせて、どんどん最適化された未来が見えてくる。
