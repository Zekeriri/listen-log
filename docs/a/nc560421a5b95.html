短文：浅睡、早睡、早起VS充足睡眠、昼夜颠倒

一口エッセイ:睡眠が浅い早寝早起きVSたっぷり眠る昼夜逆転

先日の一人旅中、ホテルのチェックアウト時間的に無理やり早寝早起きをせざるを得ないこととなったので、それを引きずって家でも生活リズムが若干良くなりました。 が、代わりに睡眠時間が極端に減った。せっかく昼夜逆転が治りつつあるのだから、この状態を維持したい！ と欲張ってしまった結果、朝の8.9時に起きるために毎日4.5時間の睡眠になってしまったのです。 1.2日睡眠時間が少ない程度であればなんともないものの、その状態が一週間近く続いた昨晩は睡眠不足がピークで、21時くらいからずっと全身がピリピリして、特に頭部には明らかに寿命を削っているタイプの頭痛が響く。具体的には電流が走っているのようなビリっとした痛みに定期的に襲われ、そのたびにビクッと身体が跳ねた。でも、『いぬやしき』が無料公開していたら、先が気になって結局読み終わるまで夜更かししてしまった（ ; ; ） さて、それはもう早寝早起きが叶ったボーナスタイムを諦め、そろそろたっぷり夕方まで眠る生活に戻ることで解決するとして、「睡眠時間が少ないけど早寝早起き」と「昼夜逆転しているけどたっぷり寝ている」場合、どちらが健康なのかと気になる。いま自分は前者ですが今までの後者の時の方が頭が回る。気になってチャットAIに訊いてみたら一般的には前者らしい。じゃあこれでいいのか。珍しくまったく普通の日記でした。
